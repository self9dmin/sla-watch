## Observed failures and remaining checks

- SAL Run JavaScript lacked `@dynatrace-sdk/client-app-settings-v2`; the route Workflow now calls the deployed app function instead. A missing synthetic review failed before the gateway, and the current review passed.
- Dynatrace normalized an ingested event timestamp from `.650Z` to `.65Z`. The route Workflow compares parsed instants while the app review gate still requires the exact saved review text. An early event failed the strict string check; another failed because the PowerShell synthetic setting writer also normalized its timestamp. The corrected synthetic fixture and Workflow passed. Newly activated event triggers did not process the first event sent immediately after activation; later synthetic events did trigger. Do not infer that activation is instantaneous.
- Production UI smoke verification remains open because control of the user's existing Chrome session timed out. The app version, scopes, Workflow executions, Grail records, and Phoenix spans were checked by API. A person should verify the manual review, queue, feedback, and filing controls in Chrome before using a real case.
- The current app records a filing only after a person supplies a provider channel and receipt or ticket reference. That is an operator attestation, not proof the provider accepted a claim. Business-event ingestion is not a server-side authorization boundary for a contract-owner role; enforce that role and a server-side `continued` check before relying on filed records for a controlled production process. Repeated manual queueing can still create repeated decisions, so high-volume use needs a durable idempotency key.
- The gateway and Laya depend on this PC, the user's logon, Docker Desktop, and network access. This is a live local-host pilot, not a highly available service. Only synthetic cases were sent through the pilot. No hosted inference API was used. Phoenix receives opaque identifiers and decision metadata, not raw case IDs, provider labels, availability measurements, prompts, or evidence text.
- Laya's 0.85 confidence and 0.8 selected-probability thresholds are uncalibrated pilot values. Low confidence, abstention, incomplete evidence, a failed model, or a missing audit trace leads to human review. Provider eligibility remains `undetermined`; provider submission remains `not_sent`. Neither the model nor a Workflow submits a claim.
- The production dependency audit passes only with a temporary, narrow exception for upstream high-severity `braces` advisory `GHSA-vfj7-8cjw-p6xm` in a Dynatrace devkit build tree, expiring 2026-11-01. The affected packages were absent from generated UI and function bundles. This is an accepted build-dependency risk, not a fix or a runtime safety guarantee.
